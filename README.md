# 수능 영어 모의고사 시계

Chrome 전체화면과 교실 전면 표시를 위한 정적 Vite/TypeScript 앱입니다. 타이머는 누적 카운터가 아니라 매 갱신마다 시스템 시각과 절대 종료 시각의 차이를 계산합니다.

## 실행

```powershell
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 Chrome으로 열고, 화면 아래의 **시험 준비 · 오디오 활성화**를 한 번 누른 뒤 전체화면으로 전환합니다. 브라우저 자동 재생 정책 때문에 이 최초 클릭은 실제 시험 전에 반드시 필요합니다.

프로덕션 빌드와 로컬 미리보기:

```powershell
npm run build
npm run preview -- --host 127.0.0.1
```

`dist` 폴더를 그대로 정적 호스팅하면 됩니다. `index.html`을 파일로 직접 여는 방식보다 로컬 정적 서버 사용을 권장합니다.

## 검사

```powershell
npm run check
```

타입 검사와 일정 엔진 테스트를 실행합니다.

## 개발용 빠른 검증

개발 서버 주소 뒤에 `?dev=1`을 붙이면 설정 패널에만 시점 점프 버튼이 나타납니다. 각 버튼은 해당 이벤트 기준 시각 1초 전으로 새 시험 세션을 설정하며, 일반 주소에서는 이 UI가 노출되지 않습니다.
